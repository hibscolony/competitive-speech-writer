Bahasa Indonesia

Expected behavior:

1. Validate that 3–5 sources are available.
2. Extract the most relevant idea from each source.
3. Define one central thesis.
4. Map evidence into 2–3 arguments.
5. Draft the speech.
6. Apply rhyme only to strategic passages.
7. Verify factual/source-dependent claims.
8. Return title, full script, source utilization, and estimated duration.
